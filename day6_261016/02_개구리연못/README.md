# [Day6-2] 개구리 연못

> 유형: 조건 시뮬레이션 (개구리 점프 유형) · 제한 시간: 2시간

## 문제
N×N 연못에서 1은 연잎, 0은 물이다. 개구리는 (r, c) 연잎 위에서 출발한다. (행·열 번호는 1부터 시작)

개구리에게 Q개의 명령이 순서대로 주어진다. 명령은 `방향 d`와 `거리 k`이며,
방향은 1=위, 2=아래, 3=왼쪽, 4=오른쪽이다.

각 명령마다 개구리는 그 방향으로 **정확히 k칸 떨어진 칸**으로 점프하려고 한다. (중간 칸은 상관없다.)
- 도착 칸이 **연못 밖이거나 물(0)이면** 점프하지 않고 그 명령은 무시한다.
- 도착 칸이 연잎(1)이면 점프하고, **개구리가 떠난 원래 칸의 연잎은 가라앉아 물(0)이 된다.**

모든 명령을 수행한 뒤 개구리의 위치와, 연못에 남아 있는 연잎 수(개구리가 앉은 연잎 포함)를 구하라.

## 입력
- 첫 줄에 T가 주어진다.
- 각 테스트 케이스의 첫 줄에 N이 주어진다. (3 ≤ N ≤ 10)
- 다음 N줄에 연못이 주어진다.
- 다음 줄에 출발 위치 r, c가 주어진다. (출발 칸은 항상 연잎)
- 다음 줄에 명령 수 Q가 주어지고, 다음 Q줄에 d, k가 주어진다. (1 ≤ Q ≤ 20, 1 ≤ k ≤ 3)

## 출력
`#t 행 열 남은연잎수` 형식으로 출력한다.
