# [Day6-1] 마름모 수확

> 유형: 행마다 범위가 바뀌는 순회 · 제한 시간: 2시간

## 문제
N×N 농장(N은 홀수)의 각 칸에 작물 가치(0~9)가 적혀 있다.
농장 정중앙을 중심으로, 농장에 꼭 맞는 **마름모** 모양 안쪽의 작물만 수확한다.

수확한 작물 가치의 합에서, 수확하지 못한 (마름모 바깥) 작물 가치의 합을 뺀 값을 구하라.

예) N=5일 때 마름모 (■ = 수확)
```
□ □ ■ □ □
□ ■ ■ ■ □
■ ■ ■ ■ ■
□ ■ ■ ■ □
□ □ ■ □ □
```

> 💡 행마다 수확하는 열의 시작과 끝이 어떻게 바뀌는지 규칙을 찾아보자.

## 입력
- 첫 줄에 T가 주어진다.
- 각 테스트 케이스의 첫 줄에 N이 주어진다. (1 ≤ N ≤ 15, N은 홀수)
- 다음 N줄에 각 행이 **공백 없이** 숫자로 주어진다.

## 출력
`#t 답` 형식으로 출력한다. (답은 음수일 수 있다.)

## 예제 입력
```
2
3
111
111
111
5
00500
01110
51115
01110
00500
```

## 예제 출력
```
#1 1
#2 29
```
