# [Day4-1] 직사각형 달팽이

> 유형: 델타 탐색 · 방향 전환 · 제한 시간: 2시간

## 문제
N행 M열 격자의 왼쪽 위 칸부터 시작해 1, 2, 3, …, N×M을 **시계 방향 달팽이 모양**으로 채운다.

처음에는 오른쪽으로 진행하다가, 격자 밖으로 나가거나 이미 채운 칸을 만나면 **오른쪽으로 90도 꺾는다.**
(오른쪽 → 아래 → 왼쪽 → 위 → 오른쪽 …)

N과 M이 다를 수 있다는 점에 주의하자.

예) N=3, M=4
```
1  2  3  4
10 11 12 5
9  8  7  6
```

## 입력
- 첫 줄에 T가 주어진다.
- 각 테스트 케이스마다 N, M이 주어진다. (1 ≤ N, M ≤ 10)

## 출력
첫 줄에 `#t`를 출력하고, 다음 N줄에 격자를 공백으로 구분해 출력한다.

## 예제 입력
```
2
3 4
1 3
```

## 예제 출력
```
#1
1 2 3 4
10 11 12 5
9 8 7 6
#2
1 2 3
```
