# [Day4-2] 물풍선 터뜨리기

> 유형: 델타 탐색 · 거리만큼 뻗기 (풍선팡 유형) · 제한 시간: 2시간

## 문제
N×M 격자의 각 칸에 물풍선이 하나씩 있고, 칸마다 물풍선의 **세기**(1~9)가 적혀 있다.

한 칸의 물풍선을 터뜨리면, 그 칸을 포함해 **상·하·좌·우 각 방향으로 세기만큼 떨어진 칸까지** 물이 퍼진다.
이때 물이 닿은 모든 칸에 적힌 숫자의 합이 그 풍선의 점수다. (격자 밖은 무시하고, 퍼진 칸의 풍선이 연쇄로 터지지는 않는다.)

물풍선 하나를 골라 터뜨릴 때 얻을 수 있는 **최대 점수**를 구하라.

예) 세기 2인 칸을 터뜨리면 위로 2칸, 아래로 2칸, 왼쪽 2칸, 오른쪽 2칸, 그리고 자기 자신까지 최대 9칸의 숫자를 더한다.

## 입력
- 첫 줄에 T가 주어진다.
- 각 테스트 케이스의 첫 줄에 N, M이 주어진다. (1 ≤ N, M ≤ 15)
- 다음 N줄에 각 칸의 세기가 주어진다. (1 ≤ 세기 ≤ 9)

## 출력
`#t 답` 형식으로 출력한다.

## 예제 입력
```
2
3 3
1 2 1
1 1 1
1 1 1
2 4
3 1 1 1
1 1 1 1
```

## 예제 출력
```
#1 6
#2 7
```
