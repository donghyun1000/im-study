## 📅 진행 방식
- **기간**: 10/12(월) ~ 10/18(일), 매일 2문제 → 총 14문제 (목록은 [`ROADMAP.md`](./ROADMAP.md))
- **마감**: 매일 23:59까지 PR 올리기
- **코드리뷰**: 다음 날 문제 풀기 전까지 다른 2명 PR에 코멘트 최소 1개씩
- **마지막 날(일)**: 실전 모의 2문제 연속 풀이 후 회고 이슈 작성

## ⏱️ 2시간 규칙
1. 타이머 켜고 시작 → **문제 읽기 + 설계 15분 / 구현 90분 / 디버깅 15분** 감각으로
2. 2시간 안에 못 풀면 **거기서 멈추고** 그 상태 그대로 제출 (실패도 기록)
3. 막힌 지점을 PR에 적은 뒤, 그때 다른 사람 풀이를 보고 **다음 날 다시 풀기**
4. 풀이 파일 맨 위에 걸린 시간을 꼭 적기 → 시간 단축 추이가 곧 실력

## 🌿 Git 규칙
- 각자 **본인 이름 브랜치**에서 작업 → `main`으로 PR
- PR은 **하루 1개** (그날 2문제 같이)
- PR 제목: `[Day1] 동현 - 최빈수 구하기, View`
- 커밋 메시지: `[Day1] SWEA 1204 최빈수 구하기 (45분)`
- **1명 이상 Approve** 받으면 본인이 merge

```bash
# 매일 시작할 때
git checkout main
git pull origin main
git checkout 동현            # 처음엔 git checkout -b 동현
git merge main

# 다 풀고 나서
git add .
git commit -m "[Day1] SWEA 1204 최빈수 구하기 (45분)"
git push origin 동현
# → GitHub에서 PR 생성
```
