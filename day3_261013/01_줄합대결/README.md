# [Day3-1] 줄 합 대결

> 유형: 2차원 이중 for · 행/열/대각선 · 제한 시간: 2시간

## 문제
N×N 크기의 숫자판이 주어진다.
**각 행의 합(N개), 각 열의 합(N개), 두 대각선의 합(2개)** 총 2N+2개의 합 중
**가장 큰 값과 가장 작은 값의 차이**를 구하라.

- 주대각선: (0,0), (1,1), …, (N-1,N-1)
- 반대각선: (0,N-1), (1,N-2), …, (N-1,0)

## 입력
- 첫 줄에 T가 주어진다.
- 각 테스트 케이스의 첫 줄에 N이 주어진다. (2 ≤ N ≤ 20)
- 다음 N줄에 숫자판이 주어진다. (1 ≤ 숫자 ≤ 100)

## 출력
`#t 답` 형식으로 출력한다.

## 예제 입력
```
2
3
1 2 3
4 5 6
7 8 9
2
5 5
5 5
```

## 예제 출력
```
#1 18
#2 0
```
