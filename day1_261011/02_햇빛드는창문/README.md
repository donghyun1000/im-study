# [Day1-2] 햇빛 드는 창문

> 유형: 1차원 for · 양옆 비교 · 제한 시간: 2시간

## 문제
일렬로 늘어선 N개 건물의 높이(층수)가 주어진다.
어떤 건물의 한 층에 햇빛이 들려면, 그 건물 **왼쪽 K칸 이내와 오른쪽 K칸 이내의 모든 건물보다** 그 층이 높아야 한다.

즉, i번 건물의 햇빛 드는 층 수는 `h[i] - (양옆 K칸 이내 건물 높이 중 최댓값)`이며, 이 값이 0 이하이면 0이다.
범위 밖(0번 왼쪽, N-1번 오른쪽)에는 건물이 없는 것으로 본다.

모든 건물의 햇빛 드는 층 수의 합을 구하라.

## 입력
- 첫 줄에 T가 주어진다.
- 각 테스트 케이스의 첫 줄에 N, K가 주어진다. (5 ≤ N ≤ 1,000, 1 ≤ K ≤ 5)
- 다음 줄에 N개 건물의 높이가 주어진다. (0 ≤ 높이 ≤ 255)

## 출력
`#t 답` 형식으로 출력한다.

## 예제 입력
```
2
8 2
0 0 3 5 2 4 9 0
5 1
4 1 4 1 4
```

## 예제 출력
```
#1 6
#2 9
```
