# [Day1-1] 카페 주문 통계

> 유형: 1차원 for · 카운팅 배열 · 제한 시간: 2시간

## 문제
싸피 카페에는 1번부터 100번까지 메뉴가 있다.
하루 동안 들어온 주문 N건의 메뉴 번호가 순서대로 주어질 때, **가장 많이 주문된 메뉴 번호와 그 주문 횟수**를 구하라.

가장 많이 주문된 메뉴가 여러 개라면 **번호가 가장 작은 메뉴**를 출력한다.

> 💡 `max()`, `Counter` 같은 내장 기능 없이 카운팅 배열로 풀어보자.

## 입력
- 첫 줄에 테스트 케이스 수 T가 주어진다.
- 각 테스트 케이스의 첫 줄에 주문 수 N이 주어진다. (1 ≤ N ≤ 1,000)
- 다음 줄에 N개의 메뉴 번호가 공백으로 구분되어 주어진다. (1 ≤ 번호 ≤ 100)

## 출력
`#t 메뉴번호 주문횟수` 형식으로 출력한다.

## 예제 입력
```
2
6
3 3 5 5 1 2
1
7
```

## 예제 출력
```
#1 3 2
#2 7 1
```
