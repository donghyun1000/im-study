# [Day5-1] 테두리 순찰

> 유형: 2차원 범위 순회 · 제한 시간: 2시간

## 문제
N×N 마을의 각 칸에 순찰 포인트가 적혀 있다.
경비원은 M×M 크기의 정사각형 구역 하나를 골라 그 **테두리 칸만** 순찰하고, 테두리 칸의 포인트를 모두 얻는다.
(정사각형 **내부** 칸은 순찰하지 않는다.)

얻을 수 있는 **포인트 합의 최댓값**을 구하라.

예) M=3이면 3×3 구역에서 가운데 1칸을 뺀 8칸의 합이다.

## 입력
- 첫 줄에 T가 주어진다.
- 각 테스트 케이스의 첫 줄에 N, M이 주어진다. (3 ≤ M ≤ N ≤ 15)
- 다음 N줄에 각 칸의 포인트가 주어진다. (1 ≤ 포인트 ≤ 30)

## 출력
`#t 답` 형식으로 출력한다.

## 예제 입력
```
2
4 3
1 1 1 1
1 9 1 1
1 1 2 2
1 1 2 2
3 3
1 2 3
4 100 6
7 8 9
```

## 예제 출력
```
#1 19
#2 40
```
