# [Day2-2] 블록 평탄화

> 유형: 1차원 for · 최대/최소 반복 · 제한 시간: 2시간

## 문제
가로로 N개의 블록 기둥이 있고, 각 기둥의 높이가 주어진다.
**덤프** 한 번은 가장 높은 기둥의 맨 위 블록 1개를 가장 낮은 기둥 위로 옮기는 작업이다.
(가장 높은/낮은 기둥이 여러 개면 아무거나 골라도 결과는 같다.)

덤프를 최대 D번 수행한 뒤 **가장 높은 기둥과 가장 낮은 기둥의 높이 차이**를 구하라.
단, 덤프 도중 높이 차이가 1 이하가 되면 더 이상 덤프하지 않는다.

## 입력
- 첫 줄에 T가 주어진다.
- 각 테스트 케이스의 첫 줄에 N, D가 주어진다. (1 ≤ N ≤ 100, 1 ≤ D ≤ 1,000)
- 다음 줄에 N개 기둥의 높이가 주어진다. (1 ≤ 높이 ≤ 100)

## 출력
`#t 답` 형식으로 출력한다.

## 예제 입력
```
2
5 3
1 5 3 3 3
4 10
4 4 4 5
```

## 예제 출력
```
#1 0
#2 1
```
