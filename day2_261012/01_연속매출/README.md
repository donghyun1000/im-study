# [Day2-1] 연속 매출

> 유형: 1차원 for · 구간합 · 제한 시간: 2시간

## 문제
어느 가게의 N일 동안의 하루 매출이 주어진다.
**연속된 M일**의 매출 합을 모든 위치에서 구했을 때, 그중 **최댓값과 최솟값의 차이**를 구하라.

## 입력
- 첫 줄에 T가 주어진다.
- 각 테스트 케이스의 첫 줄에 N, M이 주어진다. (1 ≤ M ≤ N ≤ 1,000)
- 다음 줄에 N일의 매출이 주어진다. (1 ≤ 매출 ≤ 10,000)

## 출력
`#t 답` 형식으로 출력한다.

## 예제 입력
```
2
5 2
1 2 3 4 5
3 3
5 5 5
```

## 예제 출력
```
#1 6
#2 0
```
